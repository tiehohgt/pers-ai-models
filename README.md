# Pers AI — локальные модели

Здесь лежат GGUF-модели для локального чата в приложении **Pers AI**.

Приложение не хранит модель внутри APK: оно скачивает её при первом открытии чата
или позволяет импортировать свой `.gguf`-файл.

## Qwen2.5-1.5B-Instruct (Q4_K_M)

- Файл: `Qwen2.5-1.5B-Instruct-Q4_K_M.gguf`
- Размер: 986 048 768 байт (~940 МиБ)
- Квантование: Q4_K_M
- Контекст в приложении: 2048 токенов
- Языки: русский, английский и другие
- Лицензия: Apache 2.0 (см. `LICENSE-QWEN2.5.txt`)
- Источник весов: [Qwen/Qwen2.5-1.5B-Instruct](https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct)
- GGUF-квантование: [bartowski/Qwen2.5-1.5B-Instruct-GGUF](https://huggingface.co/bartowski/Qwen2.5-1.5B-Instruct-GGUF)

Модель обучена Qwen Team (Alibaba Cloud). Это не официальный арт и не
официальное приложение; модель распространяется по Apache 2.0.

## Скачать

Прямая ссылка на файл в релизе:

```text
https://github.com/tiehohgt/pers-ai-models/releases/download/models-v1/Qwen2.5-1.5B-Instruct-Q4_K_M.gguf
```

Файл также можно скачать вручную и импортировать в приложении через
«Настройки ИИ» → «Своя модель» → «Загрузить .gguf».

## Требования

- 64-битное устройство (`arm64-v8a` или `x86_64`).
- Желательно 4 ГБ RAM и больше.
- Свободное место: ~1 ГБ на модель.
- Первая загрузка модели занимает несколько секунд; ответы на 1.5B
  квантовании Q4 — обычно несколько токенов в секунду.
